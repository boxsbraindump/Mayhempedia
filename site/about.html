About Mayhempedia

A practical ARAM: Mayhem companion.

Mayhempedia is a fan-made Windows app for the moments between a champion roll and a lobby lock-in. It turns build research into a route you can scan quickly: augments, items, and why the combination works.

01

One specific problem

ARAM: Mayhem gives players many viable choices in very little time. Mayhempedia is designed to make that choice legible, rather than hand players a generic tier list or an unexplained item sequence.

02

Built in public

Routes, combo plays, patch notes, and product changes are released in the open. The GitHub repository tracks the source, releases, issues, and technical policy so beta testers can see what changed and report what did not work.

View the project on GitHub →

03

Community-tested routes

The app is in public beta. A good report is more valuable than a polite download: tell us where the client failed, where a route was misleading, or which strange build deserves a real Combat File.

Join the beta Discord →

04

Independent and fan-made

Mayhempedia is independently maintained and is not endorsed by Riot Games. It is a display and decision-support companion, not a gameplay automation tool.
